# 한국형 사주 궁합 기본 리포트 UX와 비교 규칙 조사

- 조사일: 2026-07-31
- 질문: 한국 사용자가 두 사람의 생년월일시를 주고 “궁합 봐줘”라고 했을 때 무엇을 기대하며, 어떤 비교를 재현 가능하게 계산할 수 있는가?
- 범위: 서비스 운영사가 공개한 공식 결과 구성·상품 설명·앱 업데이트 기록, 직접 확인 가능한 고전 원문, 국내 학술자료
- 제외: 후기에서 가져온 적중 주장, 출처 없는 블로그 표, 광고성 길흉 문구의 재사용

## 결론

`두 명식에 자(子)가 공통으로 반복된다`는 사실 하나를 말한 뒤 “검증된 궁합 규칙이
없다”며 관계 해석을 중단하는 것은 좋은 기본 궁합 답변이 아니다. 한국 서비스에서
반복되는 최소 기대는 다음과 같다.

1. 두 사람의 명식을 나란히 보여 준다.
2. 이 관계를 한 문장으로 요약한다.
3. **일간 관계, 일지·배우자궁, 오행 비교, 실제 합·충 관계**를 근거로 든다.
4. 잘 맞는 지점과 부딪히는 지점을 모두 설명한다.
5. 같은 근거를 `소통`, `감정`, `생활 리듬`, `의사결정`처럼 사용자가 궁금한 관계
   장면으로 번역한다.

단일 “좋다/나쁘다” 판정이나 100점 점수는 필요하지 않다. 그렇다고 계산표만 보여 주고
해석을 거절해서도 안 된다. 적절한 기본값은 **전통 자평식 비교 프로필을 명시적으로
선택하고, 확정 계산과 전통적 의미를 구분해 자연어로 풀어 주는 것**이다.

```text
두 원국 계산
  → 일간·십신의 양방향 비교
  → 일지와 교차 간지의 관계 탐지
  → 오행의 겹침·차이 비교
  → 관계에서 잘 맞는 축과 긴장 축 선정
  → 소통·갈등 장면으로 번역
```

**역사적 규칙의 1차 자료**이지 현실 관계를 예측한다는 검증 자료가 아니다. 국내
학위논문은 사용 방법의 분류와 인터뷰 사례를 제공하지만 보편적 점수 공식을 검증하지
않는다. 세 자료층을 섞지 않는 것이 중요하다.

## 한국 서비스에서 공통으로 보이는 UX 패턴

### 1. 첫 결과는 “판정”보다 “관계의 모양”을 설명한다

사용자가 알고 싶은 것은 글자 하나의 공통점이 아니라 다음과 같은 질문이다.

- 둘은 무엇 때문에 가까워지는가?
- 서로를 어떤 방식으로 받아들이는가?
- 잘 맞는 생활 리듬과 다른 생활 리듬은 무엇인가?
- 같은 문제로 부딪힌다면 어느 지점인가?
- 연인, 친구, 가족, 동업자일 때 무엇을 다르게 봐야 하는가?

사자사주는 이를 “잘 맞는 부분 / 맞춰갈 점”으로, 자모는 “강점 / 주의점 / 조언”으로
나눈다. 표현은 달라도 **장점과 긴장을 한 화면에 함께 놓는 방식**은 같다.

### 2. 두 사람 데이터가 동시에 보여야 한다

좋은 궁합 화면은 두 사람의 원국 또는 핵심 지표를 나란히 둔다. 자모의 공식 업데이트
기록은 상대 프로필에서 그 사람 기준의 사주 상세를 열게 하고, 두 명식이 섞이지 않게
고쳤다고 밝힌다. 이는 채팅 답변에서도 중요하다.

- `A의 원국`과 `B의 원국`
- `A가 B를 볼 때`와 `B가 A를 볼 때`
- `A에게만 있는 구조`, `B에게만 있는 구조`, `둘 사이에서 생기는 구조`

이 셋을 문장 주어에서 명확히 구분해야 한다.

### 3. 총점보다 비교 축이 기억에 남는다

일부 서비스는 종합 점수를 제공하지만, 같은 공식 페이지 안에서도 점수보다 장단점과
상호작용을 강조한다. 점수는 서로 다른 학파의 규칙과 의미를 임의 가중치로 합치기 쉽다.
Oh My Saju는 총점을 만들지 않고 다음처럼 축별 결과를 보여 주는 편이 낫다.

| 비교 축               | 사용자에게 답하는 질문                              |
| --------------------- | --------------------------------------------------- |
| 일간·십신             | 서로를 어떤 역할과 방향으로 받아들이기 쉬운가?      |
| 일지·배우자궁         | 가까운 생활권에서 닮은 점과 다른 점은 무엇인가?     |
| 합·충·형·해           | 실제 두 명식 사이에 연결·긴장 표가 어디서 만나는가? |
| 오행                  | 두 사람의 기운이 어디서 겹치고, 어디서 서로 다른가? |
| 개인 원국의 표현 방식 | 의견·감정·결정을 밖으로 내는 방식이 어떻게 다른가?  |

### 4. 관계 유형이 해석의 우선순위를 바꾼다

사주온과 자모는 연인·부부뿐 아니라 가족, 친구, 직장, 사업 관계를 구분한다. 같은
계산 결과라도 연애 궁합에서는 친밀감과 생활 리듬을, 사업 관계에서는 결정권·책임·자원
운용을 먼저 설명해야 한다.

사용자가 단순히 “궁합”이라고만 하면 대화 문맥상 연애·부부 관계가 분명한 경우 그
맥락을 사용한다. 문맥이 없더라도 분석을 멈추지 말고 **기본 관계 궁합**을 먼저 제공한
뒤, 마지막에 “연애/결혼·친구·동업 중 어느 관계인지 알려주면 해당 장면을 더 자세히
볼 수 있다”고 이어 가면 된다.

## 전통 비교 축을 계산층과 해석층으로 나누기

### 전체 원칙

| 층          | 재현 가능하게 할 수 있는 일                                  | 이 층에서 하면 안 되는 일                |
| ----------- | ------------------------------------------------------------ | ---------------------------------------- |
| 계산 사실   | 두 원국, 오행·음양, 십신, 간지 관계표의 일치, 위치와 개수    | “천생연분”, “이혼한다” 같은 의미 판정    |
| 전통 프로필 | 어느 비교 축을 우선할지, 합·충을 어떤 조건에서 해석할지 선택 | 여러 학파를 출처 없이 합산, 임의 점수화  |
| 생활 해설   | 승인된 비교 결과를 소통·갈등·생활 장면으로 번역              | 계산에 없는 성격·사건·상대의 속마음 생성 |

`관계표에 맞는 쌍이 존재한다`와 `그 관계가 길하다/흉하다`는 다른 주장이다.
《三命通會》 권2도 형이나 충을 이름만 보고 곧바로 흉으로 처리하지 않고 전체 오행과
다른 조건을 함께 보며, 삼합 역시 완전한 세 글자와 성립 조건을 구분한다. 따라서
엔진은 raw match를 먼저 보존하고 해석 프로필이 그 위에 의미를 붙여야 한다.

## 안전하게 계산 가능한 비교 규칙

### 1. 두 원국과 입력 가정

두 사람 각각에 대해 다음을 먼저 확정한다.

- 양력·음력·윤달
- 출생지와 시간대
- 절기 경계와 시주
- 년·월·일·시 네 기둥
- 일간·일지
- 동일한 산식으로 계산한 오행과 십신

한국어 대화에서 별도의 해외 단서가 없으면 입력 확인을 `양력·한국 표준시 기준`으로
짧게 제시할 수 있다. 두 사람 중 출생 국가나 시간대가 다르면 각각 계산해야 한다.

출생시각이 없는 사람은 임의의 정오나 자시를 넣지 않는다. 삼주로 확정되는 일간·일지와
교차 관계는 계산하고, 시주에 따라 달라지는 결과만 별도로 표시한다. 기본 궁합 전체를
거절할 이유는 아니다.

### 2. 일간의 오행 관계

두 일간의 오행을 비교해 다음 중 하나를 방향과 함께 계산한다.

```text
같은 오행
A가 B를 생함
B가 A를 생함
A가 B를 극함
B가 A를 극함
```

여기에 천간 오합의 raw match를 별도로 붙인다.

```text
甲己, 乙庚, 丙辛, 丁壬, 戊癸
```

허용되는 표현:

> 두 일간은 수생목으로 A에서 B 쪽으로 생하는 방향입니다.

금지되는 비약:

> A가 평생 희생하고 B는 받기만 합니다.

상생·상극은 방향 관계다. 좋은 사람·나쁜 사람, 관계의 주도권, 실제 희생을 직접
증명하지 않는다. 천간합 역시 “연결점이 있다”는 전통 해석 후보이지 운명적 사랑의
보증이 아니다.

### 3. 십신의 양방향 상호작용

십신은 일간을 기준으로 정해지므로 궁합에서는 방향이 핵심이다.

```text
A 일간 기준 B 일간의 십신
B 일간 기준 A 일간의 십신
```

예를 들어 A가 양수 `壬`, B가 양목 `甲`이면:

- A 기준 B의 `甲`은 식신
- B 기준 A의 `壬`은 편인

같은 두 글자여도 `A → B`와 `B → A`의 명칭과 의미가 다르다. 이는
《三命通會》 권5의 일간 상대 생극·음양 정의에서 직접 계산할 수 있는 방향성이다.

기본 해설에서 쓸 수 있는 중립적 번역은 다음과 같다.

| 십신군    | 관계 문맥의 쉬운 번역                      |
| --------- | ------------------------------------------ |
| 비견·겁재 | 동등성, 자율권, 경쟁이나 공동 추진         |
| 식신·상관 | 표현, 제안, 반응을 밖으로 내는 방향        |
| 정재·편재 | 자원, 현실적 결과, 관리 대상으로 보는 방향 |
| 정관·편관 | 규칙, 책임, 조율 또는 압박으로 느끼는 방향 |
| 정인·편인 | 받아들임, 뒷받침, 해석과 의미 부여의 방향  |

이 표는 성격 사전이 아니다. 실제 문장에는 반드시 두 사람의 일간과 방향을 함께 쓴다.
성별에 따라 `남성의 재성=아내`, `여성의 관성=남편`을 자동 적용하는 전통적 성 역할
문장은 기본 궁합에서 제외한다. 사용자가 고전식 혼인 해석을 명시적으로 요청했을 때만
별도 프로필로 보여 주고 현대 관계의 당위로 바꾸지 않는다.

### 4. 일지·배우자궁 관계

《子平真詮評注》는 일주 궁위를 배우자와 연결하고 궁위와 십신을 함께 보도록 한다.
현대 기본 출력에서는 성별과 무관하게 일지를 **가까운 관계와 공동생활을 보는 전통적
자리**라고 한 번 풀어 쓴다.

두 일지는 다음 순서로 비교한다.

1. 같은 지지인지
2. 육합·삼합 구성에 해당하는지
3. 충·형·파·해 관계인지
4. 어느 관계도 없으면 “직접 관계 없음”인지

`같은 지지`는 별도의 고전 합 관계가 아니므로 육합처럼 표시하지 않는다. 다만 같은
오행·지장간·계절 상태가 반복되는 **공통 기반**으로 설명할 수 있다.

허용되는 표현:

> 두 사람의 일지는 모두 子라서 가까운 생활 자리의 기본 글자가 같습니다. 다만 같은
> 글자가 곧 완벽한 생활 습관의 일치를 뜻하지는 않으며, 각 원국에서 子가 받는 관계를
> 함께 봅니다.

금지되는 비약:

> 배우자궁이 같으니 반드시 결혼한다.

### 5. 두 원국 사이의 합·충·형·파·해

각 사람의 네 기둥을 교차해 `4 × 4` 위치쌍을 검사하고, 다음처럼 위치를 보존한다.

```json
{
  "relation": "六合",
  "a": { "pillar": "year", "branch": "丑" },
  "b": { "pillar": "day", "branch": "子" }
}
```

표시 우선순위는 해석 프로필이 정하되, 기본 리포트에서는 보통 다음이 읽기 쉽다.

1. 일간끼리와 일지끼리의 직접 관계
2. 한 사람의 일주와 상대 원국의 교차 관계
3. 월주끼리처럼 생활·사회 리듬과 연결해 읽을 수 있는 관계
4. 나머지 위치의 반복 관계

모든 쌍을 같은 점수로 더하지 않는다. 같은 `子丑合`이 위치만 달리해 세 번 잡혀도
“합 3점”으로 환산하지 말고, 어느 위치에서 반복되는지 보여 준다.

특히 다음을 분리해야 한다.

- `육합 쌍 발견`과 `합화 성립`
- `삼합 구성 글자 일부 존재`와 `삼합국 완성`
- `충·형·파·해 발견`과 `실제 관계 사건`
- 원국 내부 관계와 두 사람 사이에서 새로 생기는 교차 관계

형·파·해는 세부 표와 방향성에 학파 차이가 있으므로 사용한 규칙 프로필 ID를 보존한다.
기본 화면에는 규칙 ID를 노출하지 않아도 되지만, 검증 가능한 상세 근거에는 남긴다.

### 6. 오행 보완과 과잉

두 사람의 오행은 반드시 같은 산식으로 계산한 뒤 나란히 비교한다.

| 구분      | 안전하게 계산 가능한 것                     | 바로 결론 내릴 수 없는 것               |
| --------- | ------------------------------------------- | --------------------------------------- |
| 겹침      | 두 사람 모두 강하거나 반복되는 오행         | 비슷하므로 무조건 잘 맞음               |
| 차이      | A에 적고 B에 많은 오행, 그 반대             | 상대가 그 오행을 자동으로 “용신 보충”함 |
| 결합      | 두 분포를 같은 기준으로 합친 시각화         | 합친 백분율이 실제 제3의 원국이 됨      |
| 과잉 후보 | 각자 강한 같은 오행이 관계에서도 반복됨     | 그 오행 때문에 반드시 싸움              |
| 보완 후보 | 한쪽에 약한 오행이 상대에게 상대적으로 많음 | 부족한 오행은 언제나 좋은 오행          |

오행의 단순 결핍과 용신은 다르다. “A에게 금이 적고 B에게 금이 많다”는 사실은
보완 **후보**로는 표시할 수 있지만, A에게 금이 실제로 유리한지는 선택한 강약·용신
프로필의 근거가 있어야 한다.

기본 리포트에는 다음 두 문장을 분리하는 편이 좋다.

> **분포 비교:** A에게 적은 화가 B에게는 상대적으로 더 보입니다.
>
> **전통 해석:** 이것이 실제 보완으로 작동하는지는 A 원국에서 화가 필요한지까지
> 확인해야 합니다.

다만 두 번째 문장을 모든 답변의 방어 문구로 반복하지 않는다. 해당 오행을 “보완”이라고
부를 때만 가까이에 짧게 붙인다.

### 7. 갈등·소통 방식의 생성 규칙

갈등과 소통은 직접 계산값이 아니라 여러 비교 결과를 생활 장면으로 번역한 해설이다.
그러므로 최소 두 종류의 근거를 사용한다.

#### 소통 파트의 입력

- A→B와 B→A의 십신 방향
- 두 사람 각자의 식상·인성·관성 구조
- 일간의 생극 방향
- 일지의 공통점 또는 합 관계
- 실제로 있는 교차 천간합·지지합

#### 갈등 파트의 입력

- 일지와 일주 주변의 충·형·파·해
- 한쪽의 강한 표현 구조와 상대의 규칙·수용 구조가 만나는 방식
- 두 사람 모두 강한 같은 비겁·오행의 반복
- 오행 생극 방향이 한쪽으로만 몰리는 경우

#### 문장 계약

좋은 문장은 `근거 → 관계 장면 → 양면`을 포함한다.

> A 기준으로 B의 일간은 식신, B 기준으로 A의 일간은 편인으로 놓입니다. 전통적 관계
> 언어로는 A가 생각을 말과 행동으로 먼저 꺼내고 B가 그것을 해석하거나 의미를
> 붙이는 흐름으로 읽을 수 있습니다. 이 흐름이 잘 맞으면 한쪽의 아이디어를 다른
> 쪽이 깊게 받아 주지만, 어긋나면 A는 반응이 늦다고 느끼고 B는 결론이 너무 빨리
> 왔다고 느낄 수 있습니다.

나쁜 문장은 근거 없이 어디에나 적용되는 조언으로 끝난다.

> 서로 대화하고 배려하면 좋은 관계가 됩니다.

조언도 바로 앞의 긴장 구조를 풀어야 한다. `역할·기한·기준을 명확히 하라`를 모든
커플에게 반복하지 않는다.

## 권장 기본 궁합 리포트 구조

```markdown
기준: 두 사람 모두 양력·한국 표준시

| 구분 | A   | B   |
| ---- | --- | --- |
| 년주 | ... | ... |
| 월주 | ... | ... |
| 일주 | ... | ... |
| 시주 | ... | ... |
| 일간 | ... | ... |

## 두 사람의 궁합 한눈에 보기

구체적인 비교 근거 두 개가 들어간 2~3문장 총평.

## 서로를 보는 방식

| 방향  | 일간 관계 | 십신 | 쉬운 뜻 |
| ----- | --------- | ---- | ------- |
| A → B | ...       | ...  | ...     |
| B → A | ...       | ...  | ...     |

## 잘 맞는 지점

- 명식 근거 + 관계 장면
- 다른 명식 근거 + 관계 장면

## 부딪히기 쉬운 지점

- 명식 근거 + 관계 장면 + 과하지 않은 조절법

## 감정과 소통

- 두 사람의 표현·수용 방식이 어떻게 맞물리는지

## 생활 리듬과 의사결정

- 일지·월주·교차 관계를 근거로 한 구체적 차이

## 근거가 된 관계

- 일간: ...
- 일지: ...
- 천간합·지지합: ...
- 충·형·파·해: ...
- 오행 비교: ...
```

### 한눈에 보기의 품질 기준

- `물과 나무라 잘 맞는다`처럼 일간 비유 하나로 끝내지 않는다.
- 적어도 서로 다른 비교 축 두 개를 쓴다.
- 장점과 긴장점이 함께 드러나야 한다.
- “궁합 규칙이 없어 판단할 수 없다”는 내부 상태를 총평으로 내보내지 않는다.
- 큰 합충이 없으면 **없다는 사실 자체**를 말하고, 십신 방향·같은 일지·오행 차이처럼
  실제로 있는 다른 구조를 중심으로 해석한다.

## 관계 유형별 추가 파트

기본 계산은 같고 해설의 우선순위만 바꾼다.

| 관계 유형 | 먼저 설명할 장면                              | 후순위                    |
| --------- | --------------------------------------------- | ------------------------- |
| 연애·부부 | 친밀감 표현, 생활 리듬, 갈등 회복, 공동 결정  | 장기 시기는 별도 요청     |
| 친구      | 공감대, 경쟁, 연락·거리감, 함께 움직이는 방식 | 배우자성 해석 제외        |
| 가족      | 역할 기대, 간섭과 자율, 정서적 지원           | 연애 용어 제외            |
| 직장      | 보고·지시·피드백, 규칙과 자율, 책임 분담      | 친밀감·배우자궁 단정 제외 |
| 동업      | 의사결정권, 실행·관리, 자원과 위험 처리       | 결혼·자녀 해석 제외       |

성별보다 관계 유형이 먼저다. 성별 입력은 선택한 전통 프로필이나 대운 계산에 필요할 수
있지만, 기본 관계 해설을 남녀 고정 역할로 만드는 근거가 되어서는 안 된다.

## 현재 대화의 두 명식에 적용한 raw 비교 예

대상:

| 구분 | 남성 | 여성 |
| ---- | ---- | ---- |
| 년주 | 丁丑 | 丙子 |
| 월주 | 壬子 | 癸巳 |
| 일주 | 壬子 | 甲子 |
| 시주 | 乙巳 | 丁卯 |

현재 출력은 `子가 공통으로 반복된다`만 말했지만, 엔진이 적어도 다음을 계산해 보여 줄
수 있다.

1. **일간 방향:** 남성 `壬水`가 여성 `甲木`을 생한다.
2. **양방향 십신:** 남성 기준 여성 일간 `甲`은 식신, 여성 기준 남성 일간 `壬`은
   편인이다.
3. **일지:** 두 사람 모두 `子`로 같다. 직접 육합이나 충은 아니지만 가까운 관계의
   기본 글자가 겹친다.
4. **교차 천간합:** 여성 시주의 `丁`과 남성 월주·일주의 `壬` 사이에 `丁壬合`
   raw match가 반복된다.
5. **교차 지지합:** 남성 년지 `丑`과 여성 년지·일지 `子` 사이에 `子丑六合`
   raw match가 잡힌다.
6. **교차 형:** 남성 월지·일지 `子`와 여성 시지 `卯` 사이에 `子卯刑`
   raw match가 함께 존재한다.
7. **공통 글자:** `子`뿐 아니라 `巳`도 양쪽 원국에 있다.

즉 이 사례는 “같은 子가 있다”가 전부가 아니라 **일간의 생 방향과 식신↔편인
비대칭, 같은 일지, 반복되는 丁壬合·子丑合, 동시에 존재하는 子卯刑**을 함께 설명해야
하는 혼합 구조다. 연결 신호와 긴장 신호가 같이 있다는 사실을 보여 주면 충분히
궁합다운 해석을 만들 수 있다. 이를 모두 더해 `몇 점`이라고 만드는 것은 별개의 임의
규칙이다.

이 사례의 총평은 다음 정도의 구조를 가져야 한다.

> 두 사람은 일지가 모두 子라 가까운 생활권에서 반응의 결이 겹치고, 남성의 壬이
> 여성의 甲을 생하는 방향이라 생각이나 표현이 한쪽에서 다른 쪽으로 이어지기 쉬운
> 조합입니다. 다만 남성에게 여성은 식신, 여성에게 남성은 편인으로 읽혀 한쪽은 먼저
> 꺼내고 다른 쪽은 해석한 뒤 받아들이는 속도 차이가 생길 수 있습니다. 원국 사이에는
> 丁壬合과 子丑合 같은 연결점과 子卯刑이라는 긴장점이 함께 있어, 끌림의 유무보다
> 표현 속도와 가까워졌을 때의 생활 방식이 이 관계의 핵심 비교 지점입니다.

이 문장은 사건을 예언하지 않으면서도 계산된 궁합 구조를 실제로 해석한다.

      구체적인가?
- [ ] 관계 유형에 맞지 않는 연애·결혼·성 역할 문장을 섞지 않는가?
- [ ] 내부 구현 제한이나 장문의 방어 문구가 본문을 끊지 않는가?

### 실패해야 하는 출력

- `두 사람에게 子가 공통입니다. 그 이상은 검증된 규칙이 없어 판단할 수 없습니다.`
- `궁합은 82점이므로 결혼해도 됩니다.`
- `일간합이 있으니 천생연분입니다.`
- `충이 있으니 결국 헤어집니다.`
- `A에게 화가 부족하고 B에게 화가 많으므로 B가 무조건 A의 용신입니다.`
- `서로 배려하고 대화하면 좋은 관계가 됩니다.`처럼 근거 없는 범용 조언

## 최종 제품 원칙

기본 궁합은 “미래를 맞히는 기능”이 아니라 **두 원국을 전통 명리의 비교 언어로
나란히 읽는 기능**으로 정의하는 것이 가장 일관된다. 그러면 과장된 길흉·확률을
만들지 않고도 사용자가 기대하는 답을 충분히 제공할 수 있다.

- 계산값은 정확하고 대칭·방향성을 지킨다.
- 전통 해석은 선택한 프로필의 범위 안에서 실제로 한다.
- 불확실성은 해당 finding 가까이에만 짧게 둔다.
- 사용자 본문은 `잘 맞는 점`, `부딪히는 점`, `왜 그런지`, `어떻게 다르게 느끼는지`
  에 답한다.
- 점수보다 근거가 보이는 관계 서술을 우선한다.
